# 🤖 AI Facial Emotion Detection

A real-time facial emotion detection system built with Python, OpenCV, and DeepFace.

The application uses a webcam to detect faces and analyze facial expressions using AI, then displays the detected emotion and confidence score in real time.

## ✨ Features

- 📷 Real-time webcam capture
- 👤 Face detection
- 🧠 AI-based facial emotion recognition
- 😊 Happy detection
- 😐 Neutral detection
- 😢 Sad detection
- 😡 Angry detection
- 😨 Fear detection
- 😲 Surprise detection
- 🤢 Disgust detection
- 📊 Emotion confidence score
- ⚡ Real-time analysis

## 🛠️ Technologies Used

- Python 3.11
- OpenCV
- DeepFace
- TensorFlow
- Keras
- NumPy
